# 🎉 The Velvet Hall – Event Center Website

Welcome to **The Velvet Hall**, a multi-page responsive website built as the final project for Module 4 of the Coding Temple Software Engineering curriculum. This project demonstrates proficiency in HTML5, CSS3, semantic structuring, form handling, Flexbox/Grid layouts, and responsive design principles.

---

## 📄 Pages Included

| Page           | File Name       | Description                                                                 |
|----------------|------------------|-----------------------------------------------------------------------------|
| Home           | `index.html`     | Hero image, welcome message, about section, and featured event links.       |
| Events         | `pages/events.html` | Lists upcoming events with images, dates, and descriptions.                |
| Menu           | `pages/menu.html`  | A categorized table showcasing available food options.                      |
| Location       | `pages/location.html` | Location details with a placeholder map and general directions.         |
| Contact Us     | `pages/contact.html` | A working form with validation for name, email, and message fields.     |

---

## 🧱 Features & Technologies

- ✅ Semantic HTML5 and accessible layout
- ✅ Custom CSS with Flexbox & Grid
- ✅ Fully responsive across devices using media queries
- ✅ Polished navigation bar consistent across all pages
- ✅ Styled tables and forms for UI consistency
- ✅ Hero image with overlay and call-to-action
- ✅ Organized folder structure for maintainability
